# Yandex Forms JSON-RPC

## Настройки на стороне Yandex

### JSON-RPC - JSON-формат
Для отправки всего ответа в формате json, необходимо
- добавить параметр с названием `json` (ожидается сервисом)
    - выбрать опцию "Ответы на вопросы в формате json"
    - выбрать все вопросы (в модальном окне "Настройки переменных": Вопросы -> Выбрать все)
    - надпись изменится на "Ответы на все вопросы..."

#### Пример запроса от Forms
- Форма, для примера структуры, приведена на изображении `examples/form_example.png`
    - В форме выбраны все типы из конструктора форм, кроме "Города и страны", "Серия вопросов", "Оплата"
- Структура для параметра `json` приведен в `examples/answer_example.json` 

#### Типы ответов на вопросы
- Для всех вопросов с полем ввода value = введенные данные 
   - т.е. для типов "Короткий / длинный текст", "Да/Нет", "Число / Целое число", "Почта", "Ссылка", "Телефон", "Дата", "ИНН"
- Для вопросов с выбором ответа value = список ответов (даже если "Один вариант ответа")
   - каждый ответ - словарь, поле "text" содержит текст выбранного варианта
- Для вопросов "Оценка по шкале" value = список ответов по каждому критерию
    - каждый ответ - словарь с ключами 'col' (ответы) и 'row' (критерии), по которым доступны словари - поле "text" содержит текст выбранного варианта / критерия.
- Для вопросов "Файл" (загрузка файлов) value = список загруженных файлов
    - ключи каждого файла: "name" - название загруженного файла, "size" - размер загруженного файла, "namespace" - [пространство](https://yandex.ru/support/forms/ru/answers?tabs=forms_answers_server#files), где сохранен файл, "path" - путь к файлу в пространстве для хранения
